{# Dark-academia theme for the chat surface: candle-lit purple, serif type, zero border-radius, faceted clip-path geometry throughout. Chat only (DECISIONS.md #12) — the admin panel keeps its plain utility look. THREE TOKEN LAYERS, deliberately. The design prototype hand-typed ~41 rgba() strings off four base colours, so tuning an accent meant a find-and-replace across dozens of literals. Layer 1 holds channel triplets, layer 2 names the alpha steps, layer 3 is semantic. Change --amethyst-rgb once and every edge, fill and glow moves with it. CONTRAST: every text token carries its MEASURED ratio against the composited ground it actually sits on — the bubble is 0.75 alpha over the page gradient and code is 0.92 over the bubble, so measuring against the raw #0b0710 page hex flatters every number by roughly a full point. Three of the design's declared colours failed AA and were lightened per DECISIONS.md #14. The handoff calls its colours final, so these comments are the only thing stopping someone "restoring" them and silently reintroducing the exact defect this redesign exists to fix. #}
