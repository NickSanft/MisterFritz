# MisterFritz production lock.
#
# HAND-REVIEWED FREEZE, not a generated lock (plans/DECISIONS.md #9): no
# pip-tools, no uv, no extra dev tooling. The Dockerfile consumes this file
# directly.
#
# The INTENTIONAL dependency declaration lives in pyproject.toml's [project]
# table, with optional-dependency groups for voice / image / ocr / telegram /
# dev. This file is the pinned closure of those roots. Add a dependency there
# first, then pin it here.
#
# This was a raw `pip freeze` carrying a 2016-era neuroimaging stack. Removed:
# the whole fitz -> nipype chain (nibabel, nipype, pyxnat, traits, prov, rdflib,
# simplejson, configobj, configparser, acres, ci-info, etelemetry, looseversion,
# puremagic, pydot, httplib2), the google-* chain rooted solely at
# langchain-google-community, packages with zero import sites anywhere in the
# repo (pygame, pyttsx3, pdf2image, pytesseract, ffmpeg, ffmpeg-python), and the
# Python 2 `pathlib` backport. Also removed: `posthog`, which only ever
# arrived as a chromadb dependency and which chromadb dropped in 1.5.4 — see
# the note at the chromadb pin — and `distro`, which only ever arrived as a
# posthog dependency of its own. Nothing in this repo imports either, and
# tests/test_packaging.py fails if posthog comes back.
#
# Three packages were ADDED because the old freeze omitted them, so the
# "lock" did not actually lock: `zstandard` (required unconditionally by
# langsmith - NOT by faster-whisper, as an earlier draft of this header
# claimed), plus `av` and `ctranslate2`, which faster-whisper does require
# and which nothing else pulls in.
#
# DO NOT ADD A `fitz` PIN. `import fitz` is provided by PyMuPDF, below. The
# package published as `fitz` on PyPI is unrelated neuroimaging software that
# claims the same fitz/ directory; whichever wheel installs last wins. If it
# wins, `import fitz` SUCCEEDS - so document_engine's `except ImportError` guard
# never fires - and fitz.open() then raises AttributeError deep inside PDF
# ingestion. tests/test_packaging.py fails if that pin comes back.
#
# SECURITY-CRITICAL, and easy to lose in a regeneration:
#   nh3      - sanitises Fritz's rendered markdown. python-markdown passes raw
#              HTML through verbatim and the chat template renders it with
#              `| safe`, so dropping nh3 silently reopens stored XSS.
#   Pygments - backs markdown's codehilite. Without it the extension raises at
#              render time and every chat reply 500s.
